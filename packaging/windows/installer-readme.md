## Installation

Wähle eine Installation nur für dein Benutzerkonto, wenn du keine Administratorrechte verwenden möchtest. Eine Installation für alle Benutzer benötigt Administratorrechte.

Choose a per-user installation if you do not want to use administrator permissions. An all-users installation requires administrator access.

## Updates

Nach dem Start kannst du unter **Updates** zwischen stabilen Releases und Alpha-Vorabversionen wählen. Dort stellst du auch ein, ob der Update-Prüfer bei der Windows-Anmeldung laufen soll.

After launch, open **Updates** to choose stable releases or alpha pre-releases. You can also enable or disable update checks at Windows sign-in.

## Datenschutz / Privacy

Tastencodes werden lokal verarbeitet. Geschriebener Text wird nicht gespeichert oder übertragen.

Key codes are processed locally. Typed text is not stored or transmitted.
